# Ai Bridge

将 MarginNote 中工作流指定的卡片内容及手写图片传入 DeepSeek、ChatGPT 或 Gemini 网页。默认顶部只显示 **DeepSeek / 设置**，可在“设置 → 关于插件”启用 GPT、Gemini，至少保留一个网页。整条顶栏可拖动，右下角保留窗口缩放手柄。各网站使用独立页面，切换保留页面与草稿，首次打开时才加载。豆包适配代码保留，用户入口暂时隐藏。

当前正式版本为 **1.0.0**，安装包为 `Ai Bridge-v1.0.0.mnaddon`。最低安装版本为 **MN 4.5.0**；图片及完整卡片读取使用 MN5 的官方 `AddonWebPanel`、`window.mn` 和媒体接口。使用时需要在当前沉浸式场景模板中启用 Ai Bridge，具体接口是否开放以宿主的能力清单为准。直接登录网站使用，无需 API Key，无需安装 MN Utils。

## 安装与使用

1. 使用 `Ai Bridge-v1.0.0.mnaddon` 安装并启用插件；如使用场景模板，在模板插件列表中启用 Ai Bridge。
2. 在 **设置 → 工作流** 新增工作流，填写名称、目标网页、卡片条目、手写来源和提示词，然后保存。
3. 在脑图中选中一张卡片，打开目标网页并登录。
4. 点击网页输入区的 **三横线**，从菜单中选择工作流。DeepSeek 入口仍在智能搜索右侧，GPT 仍在原生 ＋ 右侧，Gemini 位于输入区“＋”右侧；三个网页入口统一使用透明底、深色三横线。
5. 网页菜单选择后始终向当前 AI 上传，只使用工作流的卡片范围、手写来源和提示词，不跳到工作流指定网站。桌宠菜单执行时才打开指定网站。检查附件和输入框后自行点击发送，插件不会自动发送。

设置页分类为 **桌宠 / 工作流 / 关于插件**。工作流库替代原通用上传设置，工作流按各自配置执行；历史通用设置不再显示。

只有点击上传才会读取所选内容。读取过程中会临时显示官方媒体读取面板，完成后自动收起。不会修改卡片、保存正在编辑的笔迹或切换手写层。

## 桌宠工作流

在 **设置 → 工作流** 点击“新增工作流”，设置名称、桌宠打开的网页、卡片条目、手写来源和提示词，点击“保存工作流”。最多保存 20 个，支持编辑和删除；每个工作流独立保存，不改动通用上传设置。也可以清空卡片条目、手写选“无”，只填写提示词。

插件自带“哦鲸鲸”桌宠，可在设置中切换自带角色、导入动作包或图片。在脑图中选中一张卡片，点击桌宠右上角的**三横线**，再点上方菜单中的工作流名称。插件会打开对应 AI 网页，等待输入区就绪，再按该工作流范围读取并上传；网页隐藏在导航设置中时临时显示它的入口，不改动导航偏好。没有登录时先登录，再重新执行。上传后检查附件并自行点击发送。

工作流与导入的桌宠均从 MN 文档目录中的 `AI-Bridge` 文件夹读取和保存，不自动迁移或清理旧目录。在“设置 → 桌宠”选择已导入角色，点击“删除当前桌宠”并确认即可清除该角色；删除正在使用的角色会切回自带“哦鲸鲸”，显示开关和外观设置保留。

桌宠菜单中的“管理工作流”可直接打开上述设置位置。等待或读取期间切换卡片、网站、关闭面板或进入后台会停止执行；已交给网页的内容仍需用户检查。工作流保存在 MN 文档目录的插件专用 JSON 文件中，读取或保存失败会保留原文件和编辑草稿。

卡片图片按所选条目顺序在前，另选的手写在后；同一图片重复选中时只传一次。卡片文字保留 Markdown 和公式，已作为附件上传的 MN Markdown 图片引用不重复填入正文。

## 桌宠

在「设置 → 桌宠」导入角色，桌宠选项即时生效。保留显示、导入及必要的外观调整，不包含原 MN Pet 的 AI、讲解、批改、互动面板和随机动作功能。

- **导入动作包**：选择原 MN Pet 支持的 `.mnpet` 文件，导入后显示封面并播放 idle 待机动画。支持切回已保存的图片角色。
- **导入图片**：支持 PNG、JPG、WebP。在本地调整位置、缩放和名称后，点击「导入并显示」。保存为透明 256×256 PNG；图片角色静态显示，不生成动画。
- **显示与位置**：显示开关、64–128 大小和 35%–100% 不透明度即时保存。关闭主面板后桌宠继续显示，直接拖动桌宠调整位置；进入后台暂停播放，恢复场景后继续显示。
- **保存**：各保留一个动作包和一个图片角色。新导入自动切换使用；两种角色可以随时切换。角色只保存在 Ai Bridge 自己的文稿目录，不读取或改写 MN Pet 的设置与素材。
- **文件限制**：动作包最多 10 MiB，展开素材最多 8 MiB，单个素材最多 2 MiB；原图片最多 10 MB，保存的 PNG 最多 512 KiB。失败或取消不替换旧角色。

桌宠模块提取并改编自本机 `Ds Pet` 的 MN Pet 实现，未修改原项目。导入和显示不依赖 AI 服务；Ai Bridge 原有网页上传功能保留。安装包预装“哦鲸鲸”，也支持自己的 `.mnpet` 包或图片。

## 限制与故障处理

- 首版按单张选中卡片上传，不自动遍历子卡或整个学习集。
- 单批最多 5 张图片、合计 10 MiB；卡片文字最多 18 万字符，附加提示词最多 1 万字符。这些是插件处理上限，各网站的实际限制以网站为准。
- 卡片内容最多勾选 200 条，支持第 1 至第 10000 条的序号配置；所选卡片缺少指定条目时会提示调整设置，不会悄悄跳过。
- 脑图手写仅读取所选卡片对应的媒体项，不对整个脑图屏幕截图。没有已保存笔迹时会提示，不用其他卡片或评论手写代替。
- 若网页提示找不到附件控件，先点击当前网站自身的附件按钮，让网页建立文件控件，再重试。网站结构可能改版，适配需实际登录后的网页验证。
- 原有草稿会保留并追加文字；读取期间继续编辑草稿、切换卡片/学习集/对话、切换网站、关闭面板或切换设置都会停止待上传任务。
- 已交给网页的附件可能继续由网站处理。失败或结果不明确时先检查网页，避免重复添加。
- 网站如何处理图片、是否提供文字识别及其模型能力，由网站决定；插件只负责传递，不额外识别笔迹。
- 登录态由网站 WebView 管理。插件不提取 Cookie，也不使用其他浏览器的登录信息。

## 验证情况

自动测试覆盖设置迁移、多选条目保存、三种手写来源、最后手写定位、条目缺失提示、图片 OCR 排除、上传顺序与去重、原生窗口布局、网页按钮恢复、草稿保留及取消清理，也覆盖 GPT 富文本与 textarea、附件交付、页签顺序、独立网页状态和跨网站任务隔离。设置页面交互使用实际构建出的页面测试。此前 DeepSeek 浏览器附件交付检查已通过；GPT 当前通过模拟网页测试，并用浏览器真实点击复现了原 iframe 命令被网页规则拦截的问题；已改为原生拦截页面跳转命令，仍需在 MN 内验证实际登录后的页面。豆包已检查当前官网输入引擎、附件按钮标识和窄图标壳布局；本地浏览器已验证插件真实点击、PNG 图片粘贴、草稿保留、多行文字及公式追加和无自动发送。该检查不等同于豆包服务端附件上传完成。

当前开发环境为 Windows，无法直接运行 iPad/macOS 的 MarginNote。**MN 内窗口、场景媒体接口、四个网站登录后的实际输入区与服务端附件上传仍需真机验收**；本地测试不代表这些环节已通过。Gemini 已对照当前官网输入框与工具组件的公开 DOM，并在本地浏览器验证按钮真实点击、图片交付、文字追加和无自动发送。

建议真机依次验证：勾选第 1、第 2 条，单选后续条目，只传最后手写，只传脑图手写，卡片内容与手写一起传入；确认未选内容与图片 OCR 没有混入，检查上传位置、顶栏拖动与页签点击，再测试换卡和关闭面板。

## 开发

```powershell
npm ci
npm run check
npm test
npm run build
```

默认构建只替换固定测试包，并解压逐文件比对源码和资源。正式打包使用 `npm run build:release`，版本由用户指定，拒绝覆盖同名正式包。

- `src/`：JavaScriptCore 原生窗口、设置、卡片选择及传输控制。
- `web/src/deepseek.js`：DeepSeek 网页输入和附件适配。
- `web/src/doubao.js`：豆包网页输入和附件适配，按 Tiptap 段落读取草稿，避免换行校验误报；无唯一附件控件时使用图片粘贴交付。
- `web/src/gpt.js`：ChatGPT 网页输入和附件适配。
- `web/src/gemini.js`：Gemini 的 Quill 输入区、附件组件和图片交付适配。
- `web/src/composer-bridge.js`：网站共用的草稿追加、图片交付与任务校验。
- `web/src/media-reader.js`：官方场景页面中的只读卡片与图片读取。
- `web/src/settings.*`：设置页面，通过 bridge 交由原生保存偏好。
- `src/AIBPet*.js` 与 `web/src/pet-*`：独立的桌宠显示、动画、导入校验、本地保存和设置页面。
- `assets/icon.png`：用户提供的 AI 图标原图，构建时居中缩放为透明工具栏图标。

参考本机 Jifengjincao Bridge 的浮窗和脑图手写读取流程，以及 Gemini Bridge 的窗口边界处理；未修改参考项目。
